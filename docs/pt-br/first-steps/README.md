Os workshops de primeiros passos são introduções guiadas para explorar o GitHub Copilot sem exigir uma base de código existente nem um cenário de desenvolvimento detalhado. Cada workshop começa com uma tarefa pequena, apresenta o produto enquanto você o utiliza e conduz você por um fluxo de trabalho completo.

Todos os workshops criam o mesmo Space Quiz a partir de uma pasta vazia, para que você possa escolher a ferramenta que quer conhecer ou concluir mais de um para comparar como cada uma funciona.

> [!NOTE]
> Estes workshops foram criados por [James Montemagno][james] e adaptados de [First Steps with GitHub Copilot][source-lab], disponível sob a [licença MIT][source-license].

## Workshops

### [Tour do aplicativo GitHub Copilot][copilot-app]

Crie um Space Quiz colorido a partir de uma pasta vazia e percorra o ciclo de desenvolvimento: criar, aprimorar, testar, registrar instruções do projeto, publicar, planejar o trabalho, implementar issues, revisar e mesclar um pull request, automatizar tarefas recorrentes e explorar um fluxo de trabalho com Canvas.

### [Primeiros passos com o GitHub Copilot CLI][copilot-cli]

Conheça o fluxo centrado no terminal: crie o projeto e revise os diffs antes de qualquer gravação no Git, execute sessões lado a lado em worktrees, planeje antes de editar, gerencie o contexto e, depois, crie, mescle e delegue pull requests sem sair do shell.

### [Primeiros passos com o Visual Studio Code][vscode]

Use o fluxo no editor: crie o projeto em um espaço de trabalho, aprimore elementos pelo navegador integrado, inspecione o contexto, teste antes de gravar no Git, planeje antes de editar e deixe as ferramentas do GitHub cuidar de issues, pull requests e sessões na nuvem sem sair do VS Code.
